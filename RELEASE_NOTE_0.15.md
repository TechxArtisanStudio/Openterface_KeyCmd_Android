# KeyMod 0.15 (versionCode 15)

KeyMod **0.15** ships the **gamepad** preset pipeline (**preset store v7**, layout schema **v6**–**v7**), **multi-touchpad** layouts, touchpad **mouse button** sizing, the **Keyboard & Mouse (Basic)** tier, and **KeyMod** branding on the welcome flow and build artifacts (`applicationId` unchanged). Recent **gamepad UI** work includes preset list fixes, **AppCompat** preset picker, bundled **emu-6** layout, **navigation drawer** edge lock in gamepad mode, diagonal gesture tuning, **export creator** i18n, and **toolbar** order (**preset cycle** before **active preset** dropdown). **Keyboard & Mouse Pro** is unchanged.

**Full change list, breaking migrations, and upgrade notes:** see [CHANGELOG.md](CHANGELOG.md) section **\[0.15\] — 2026-05-09**.
